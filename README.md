# Evaluaciones · WhatsApp en HubSpot

Evaluaciones de las capacitaciones de WhatsApp en HubSpot para Ferremayoreo Elizondo, preparadas por Black & Orange.

- Página principal: lista las 5 sesiones.
- Cada sesión se abre con `?sesion=1` … `?sesion=5`.
- Al terminar, la persona ve su calificación y la explicación de cada respuesta.
- Los resultados se guardan en un Google Sheet mediante una aplicación web de Apps Script (constante `SHEET_URL` en `index.html`).
